# Logo

`autoscore-mark.svg` to znak z kierunku „Scena”: tarcza z czterech kół w `color-accent`, `color-bg` i `color-text`. Stoi zawsze obok napisu „AUTO SCORE” w stylu `wordmark`, w 32 px na górnym pasku. Kolory są wpisane w plik, więc znak nie zmienia koloru przez CSS. Nie stawiaj go na `color-accent`.
