# Ikony

Zestaw ikon z aplikacji (`packages/web/src/components/icons.tsx`), siatka 24×24, jeden kolor wypełnienia. W pliku SVG wypełnienie to `color-text` (#f3ecd8), a w kodzie aplikacji `currentColor`, więc ikona bierze kolor tekstu obok. Ikona zawsze stoi obok tekstu albo ma `aria-label` na przycisku: kolor nie niesie znaczenia sam (`bust.svg` obok słowa „Bust”, `trophy.svg` obok zwycięzcy, `warning.svg` przy rzutce do weryfikacji).
